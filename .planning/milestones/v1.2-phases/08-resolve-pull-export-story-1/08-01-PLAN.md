## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated client → `GET /api/notebooks/{id}/export` | Session/token caller requests zip of a notebook they can read |
| Export zip → local filesystem (CLI unzip) | Portable Markdown leaves the server; must not embed secrets or foreign-notebook content |
| Exported Markdown → remote attachment origin | Absolute URLs point at `/attachments` on the public origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Information Disclosure | Wiki rewrite in `ExportNoteMarkdown` | medium | mitigate | Resolve only within the exported notebook’s note set + same notebook name; never consult cross-notebook readable graph (RESEARCH security) |
| T-08-02 | Tampering | Attachment URL rewrite | medium | mitigate | Only rewrite paths matching canonical `/attachments/images/{digits}/…`; do not honor arbitrary absolute URLs or open redirects |
| T-08-03 | Information Disclosure | Zip contents / workspace | high | mitigate | Do not write credentials/tokens into zip; keep sync metadata out of note entries (already matched; do not regress) |
| T-08-04 | Elevation of Privilege | `NotebookController.exportNotebook` | high | mitigate | Keep `authorizationService.assertReadAuthorization(notebook)` before building zip |
