# Phase 12 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase goal:** After navigating away via a matched title from the resolve dialog, the user can return to the accidental-match result, open the resolve dialog again via the existing CTA, and see the same matches. Requirement AMR-05. E2E polish for reopen-after-title-navigate (capability-named).

**Inheritance:** Spacing, typography, color, Resolve CTA chrome, Modal dismiss, match row title/path, Build-a-link / Add-as-overlapped CTAs, and Phase 7–11 testids are **unchanged**. This phase adds **no new visual chrome**. Sources: `07-UI-SPEC.md`–`11-UI-SPEC.md`, CONTEXT D-01..D-08, RESEARCH (KeepAlive happy path), AMR-05.

**Primary recommendation (auto):** Prefer Vue KeepAlive reactivation of `RecallPage` after history back — expect **zero new UI components** and **zero copy changes**. Product work, if any, is session/cursor restore only — not new surfaces.

## Interaction Contract

### Observable behavior (AMR-05)

Canonical happy path — product + E2E:

1. User is on accidental-match spelling result with **Resolve accidental match** visible (`matchedNotes.length > 0`).
2. User opens Resolve → dialog lists match title(s) (+ paths when hydrated).
3. User clicks a matched **title** (`NoteTitleWithLink` → real `noteShow` router navigation). Dialog **closes** on `route.fullPath` change (existing Modal). Do **not** `preventDefault` title clicks.
4. User inspects note show, then returns via **history back** (browser back / `cy.go('back')` equivalent) to the accidental-match result under recall.
5. After return: same accidental-match **alert** + **Resolve accidental match** CTA + same `matchedNotes` must be visible again (KeepAlive-preferred live session).
6. User clicks Resolve again → dialog lists the **same** match title(s) (paths hydrate as today).

### Reopen affordance (locked)

| Rule | Contract |
|------|----------|
| Manual reopen | Minimum bar = click existing Resolve CTA after return (D-02) |
| Auto-reopen | **Forbidden** this phase — no global store/query that reopens Modal without CTA click |
| Return path | History back only for product+E2E (D-03). Do **not** require Recently Recalled; do **not** use Main-menu Resume (`resumeRecall` clears answered cursor) |
| Match persistence | Prefer live `previousAnsweredQuestions` / KeepAlive; no OpenAPI enrichment unless KeepAlive path proven broken (D-04) |

### Layout order after return — unchanged

1. Outcome alert (`accidental-match-alert`)
2. Resolve `PopButton` (gated on ACCIDENTAL_MATCH + `matchedNotes.length > 0`)
3. `NoteUnderQuestion` → `ViewMemoryTrackerLink` → reviewed `NoteShow`
4. OVERLAP try-again branch unchanged / uncoupled

### Test IDs — reuse only

| Element | `data-testid` |
|---------|----------------|
| Resolve CTA | `resolve-accidental-match` |
| Dialog container | `accidental-match-resolve-dialog` |
| Match row | `resolve-match-row-{id}` |
| Accidental-match alert | `accidental-match-alert` |

Do **not** invent `back-to-result`, `reopen-resolve`, or auto-open markers.
