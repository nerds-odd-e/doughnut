## Interaction Contract

### Layout order (result chrome)

1. Outcome alert (`accidental-match-alert` when applicable)
2. Resolve `PopButton` (**only if** `outcome === "ACCIDENTAL_MATCH"` **and** `matchedNotes.length > 0`)
3. `NoteUnderQuestion` → `ViewMemoryTrackerLink` → reviewed `NoteShow`
4. OVERLAP try-again branch unchanged (separate `v-if`; never share Resolve gate)

**Forbidden on result:** `matched-notes-section`, matched `NoteShow`s, per-match link `PopButton`s.

### Open

- User click on Resolve CTA opens **one** in-repo `Modal` via `PopButton` (`showModal`).
- Do **not** auto-open on answer submit.

### Dialog body

- Component: new presentational `AccidentalMatchResolveDialog` under `frontend/src/components/recall/`.
- Props: `matchedNotes: NoteTopology[]` only.
- Do **not** require `closer` in Phase 7 (Modal dismiss covers AMR-03).
- Render vertical `<ul class="flex flex-col gap-2">` of titles; one `<li>` per match; key/`data-testid` by `matched.id`.
- No path/breadcrumb, no clickable titles, no per-row actions, no `NoteShow`, no nested `PopButton`.

### Dismiss (AMR-03)

Reuse existing Modal only — all must leave user on the accidental-match result:
- Overlay **X** (`.close-button`, `showCloseButton` default true)
- Backdrop / panel-wrapper mousedown (`close_request`)
- ESC via `modalStack`
- Route `fullPath` change close

No forced wizard; dismiss anytime without resolving.

### Test IDs (capability-named)

| Element | `data-testid` |
|---------|----------------|
| Resolve CTA | `resolve-accidental-match` |
| Dialog container | `accidental-match-resolve-dialog` |
| Match row | `resolve-match-row-{id}` |
| Accidental-match alert (existing) | `accidental-match-alert` |

Removed selectors: `matched-notes-section`, `matched-note-{id}`, `link-to-matched-note-{id}` on the result surface.

### CTA visual spec

```
PopButton
  title / aria-label: "Resolve accidental match"
  btn-class: "daisy-btn daisy-btn-secondary daisy-btn-sm mt-2"
  data-testid: "resolve-accidental-match"
  showCloseButton: true (default)
```
