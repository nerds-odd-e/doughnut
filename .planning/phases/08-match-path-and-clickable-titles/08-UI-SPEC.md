# Phase 8 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase goal:** Each resolve-dialog match is identifiable by notebook path/breadcrumb and reachable by a clickable title (identity only — no note body / peek). Requirement AMR-04.

**Inheritance:** Spacing scale, shell typography/color, CTA chrome, Modal dismiss, and Phase 7 testids are unchanged unless this contract names a delta. Source: `07-UI-SPEC.md` + CONTEXT D-01..D-11.

## Spacing Scale

Declared values (must be multiples of 4) — **inherited from Phase 7**:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon gaps inside breadcrumb (`gap-1` on notebook/folder links) |
| sm | 8px (`gap-2`) | Vertical gap between match rows in dialog list; title→path stack gap inside a row |
| md | 16px | Default element spacing |
| lg | 24px | Existing result chrome elsewhere; not between alert and Resolve CTA |
| xl | 32px | Layout gaps (not primary) |
| 2xl | 48px | Major section breaks (not primary) |
| 3xl | 64px | Page-level spacing (not primary) |

**Phase-specific spacing:**

| Location | Value | Class / rule |
|----------|-------|--------------|
| CTA under alert | 8px top margin | `mt-2` on Resolve `PopButton` (unchanged) |
| Match list | 8px row gap | `flex flex-col gap-2` on dialog `<ul>` (unchanged) |
| Inside match row | 8px title→path gap | `flex flex-col gap-2` (or equivalent `gap-2`) on the row stack — title first, path under |
| Modal panel padding | 20px 30px | Existing `.modal-container` — do not restyle |
| Modal body vertical margin | 20px | Existing `.modal-body` — do not restyle |
| Breadcrumb icons | 14×14px | Existing `h-3.5 w-3.5` on BookText / Folder — do not resize |

Exceptions:
- Modal close control remains existing **26×26px** hit area — inherit, do not redesign.
- Do **not** add extra vertical padding/skeleton chrome while path is hydrating.
- Do **not** use `mt-6` between alert and Resolve CTA.

Exactly three sizes, two weights for this phase surface (Phase 7 roles + path at Label):

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Body | 16px (`text-base`) | 400 | 1.5 | Match titles via `NoteTitleWithLink` / `NoteTitleComponent`; alert message body |
| Label | 14px (`text-sm`) | 400 | 1.5 | Resolve CTA (`daisy-btn-sm`); path via `BasicBreadcrumb` (`text-sm daisy-breadcrumbs`) |
| Emphasis | 16px (`text-base`) | 600 (`font-semibold` / `<strong>`) | 1.5 | Accidental-match alert message (`<strong>`) |

## Interaction Contract

### Layout order (result chrome) — unchanged from Phase 7

1. Outcome alert (`accidental-match-alert` when applicable)
2. Resolve `PopButton` (**only if** `outcome === "ACCIDENTAL_MATCH"` **and** `matchedNotes.length > 0`)
3. `NoteUnderQuestion` → `ViewMemoryTrackerLink` → reviewed `NoteShow`
4. OVERLAP try-again branch unchanged

**Forbidden on result:** `matched-notes-section`, matched `NoteShow`s, per-match link `PopButton`s.

### Dialog body (AMR-04)

- List host: `AccidentalMatchResolveDialog` — still presentational list of `matchedNotes: NoteTopology[]`.
- Per row: thin **`AccidentalMatchResolveRow`** under `frontend/src/components/recall/` (CONTEXT D-05 / RESEARCH recommendation).
- **Row stack (locked):**
  1. Clickable **title first** — `NoteTitleWithLink` with `:note-topology="matched"` (navigates via `noteShowLocation`)
  2. Notebook **breadcrumb under** — `BreadcrumbWithCircle` with `notebookRealm` + `ancestorFolders` **only when** that row’s `NoteRealm` is present
- Never mount `NoteShow` / note body / content peek in the dialog.
- No per-row mutation actions yet (Build a link / Add as overlapped = Phase 9+).
- No nested `PopButton` inside the resolve Modal.

### Hydrate timing (D-08 / D-09)

- Start realm hydrate when dialog body mounts (PopButton `v-if` Modal on open) via `getNoteRealmRefAndLoadWhenNeeded(matched.id)`.
- Do **not** prefetch match realms on accidental-match result mount before CTA click.
- Title is visible and clickable immediately from `NoteTopology`.
- Breadcrumb appears per-row when that realm arrives; brief missing path is OK.
- Do **not** block the whole list on the slowest match; no list-level Suspense / wait-for-all.

### Title navigation (D-06 / D-07)

- Title click navigates to matched note (`noteShow`); leaving recall is allowed.
- Existing Modal `route.fullPath` watch closes the dialog — expected; do not prevent navigation to keep dialog open.
- Do **not** implement AMR-05 reopen-after-return polish in this phase.
- Breadcrumb folder/notebook segments: follow existing `BreadcrumbWithCircle` / `BasicBreadcrumb` clickable defaults (may also leave recall) — do not force display-only.

### Dismiss (AMR-03) — unchanged

Overlay X, backdrop, ESC via `modalStack`, route change close — all leave user on result when they dismiss without navigating away.

### Test IDs (capability-named)

| Element | `data-testid` |
|---------|----------------|
| Resolve CTA | `resolve-accidental-match` |
| Dialog container | `accidental-match-resolve-dialog` |
| Match row | `resolve-match-row-{id}` |
| Match path wrapper | `resolve-match-path-{id}` (present only when realm/breadcrumb rendered) |
| Accidental-match alert (existing) | `accidental-match-alert` |

Title link: no extra testid required — assert `router-link` / `a[href]` toward match inside `resolve-match-row-{id}` (RESEARCH).

Removed selectors remain removed: `matched-notes-section`, `matched-note-{id}`, `link-to-matched-note-{id}` on the result surface.

```
  btn-class: "daisy-btn daisy-btn-secondary daisy-btn-sm mt-2"
  data-testid: "resolve-accidental-match"
```

```
      :ancestor-folders="realm.ancestorFolders ?? []"
      :notebook-realm="realm.notebookRealm"
    />
  </div>
</li>
```

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Applicable state considerations resolved: 8 covered, 2 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Resolve CTA + match list | ✅ covered | Empty or missing `matchedNotes` (or non-ACCIDENTAL_MATCH) omits CTA; no empty dialog / no empty-state copy (Copywriting Contract) |
| loading | Match path breadcrumb | ✅ covered | Progressive reveal: title immediate; path omitted until realm hydrates; no skeleton/spinner/list gate (D-08/D-09) |
| error | Match path hydrate | ✅ covered | No dedicated error/retry UI; failed or missing realm leaves title-only row (still clickable); Copywriting Error = N/A |
| populated | Match row title + path | ✅ covered | Title link + `BreadcrumbWithCircle` under it once realm present; all matches listed together |
| partial | Match path per row | ✅ covered | Some rows may show path while others still title-only; independent per-row hydrate; do not wait for all |
| overflow | Match list | ✅ covered | Modal `.modal-container` already `max-height: 100dvh; overflow: auto` — long lists scroll inside panel |
| overflow | Path breadcrumb | ✅ covered | `BasicBreadcrumb` uses `max-w-full` + DaisyUI breadcrumbs; wrap/reflow inside row — do not truncate with ellipsis this phase |
| zero-one-many | Match list | ✅ covered | Zero → no CTA; one and many → same `gap-2` list (no pluralized chrome / progress cue — AMR-12 deferred) |
| long-text | Match titles | 🧪 backstop | Long titles wrap as normal text in the row (no truncate/ellipsis); verify visually or with held-out long-title fixture if added |
| long-text | Notebook / folder path names | 🧪 backstop | Long path segment names wrap via existing breadcrumb chrome; verify visually if extreme lengths appear |

## Accessibility (phase minimum)

| Requirement | Contract |
|-------------|----------|
| CTA name | Accessible name = visible label **Resolve accidental match** |

## Out of Scope (do not design)

- AMR-05 reopen-after-title-navigate polish / remount guarantees (Phase 12)
- Build a link / readonly empty explanation (Phase 9 / AMR-06, AMR-07, AMR-13)
- Add as overlapped; progress cues; quiet linked state (Phases 10–11 / AMR-08..12)
- OpenAPI enrichment of `matchedNotes` with path; widening `NoteTopology`
- Plain-string notebook label instead of `BreadcrumbWithCircle`
- New modal libraries, DaisyUI stock `daisy-modal` markup fork, nested `PopButton` inside resolve Modal
- List-level skeleton / Suspense / “wait until all paths load”
- Changing ACCIDENTAL_MATCH / OVERLAP grading or SRS (ADR 0003 product constraint)
