# Web autosave clock precision

Source: [SEED-009 Story 10a](../../seeds/SEED-009-git-backed-local-notebook-workflow.md#story-10a),
a bounded correction of completed quick/071 Story 10.
Status: planned; generated by execution retrospective, not executed.

## Goal and scope

Preserve the save clock's milliseconds through durable amendment eligibility so
same-note saves obey the existing nonnegative, strictly-less-than-ten-minutes
rule. Keep immediate saves, no-op timing, exposure freezing, note identity,
learning data, and existing synchronization limits. No UI, API changes,
configurable timeout, history repair, or broad TIMESTAMP/2038 migration.
